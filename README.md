# PO Splitter — แยกไฟล์ใบสั่งซื้อ PDF และตั้งชื่ออัตโนมัติ

เว็บสำหรับแยกไฟล์ PDF ใบสั่งซื้อ (PO) ที่สแกนรวมกันมาเป็นไฟล์เดียว ออกเป็นไฟล์ละ 1 ใบ
และตั้งชื่อไฟล์เป็น **`เลข PO - สิ่งที่ซื้อ.pdf`** โดยใช้ OCR อ่านภาษาไทยในเบราว์เซอร์
พร้อมบันทึกการใช้งานลง Google Sheets

```
POL6911-0043 - ผลิต Content Facebook เดือนตุลาคม 2569.pdf
POL6911-0054 - ซองจดหมาย Size 9 แบบไม่เจาะหน้าต่าง.pdf
PO0001-70 - สเปรย์เคลือบกันหนู.pdf
```

## ความสามารถ

- ลากไฟล์ PDF มาวาง (หลายไฟล์พร้อมกันได้) — ระบบแยก **1 หน้า = 1 เอกสาร**
- OCR ภาษาไทย+อังกฤษ อ่านเลข PO และ **ชื่อสินค้ารายการแรก** ให้อัตโนมัติ (~4–5 วินาที/หน้า)
- รองรับ 2 แบบฟอร์มในตัวอย่าง: Lamina (`POL6911-0043`) และแบบ `P/O No. PO0001/70`
- ตรวจ/แก้เลข PO และชื่อสินค้าได้ก่อนดาวน์โหลด (ช่องที่อ่านไม่ได้จะเป็นสีเหลือง)
- ใบ PO ที่มีหลายหน้า: ติ๊ก “ต่อจากหน้าก่อน” เพื่อรวมเป็นไฟล์เดียว
- ติ๊ก “ไม่ส่งออก” เพื่อข้ามหน้าที่ไม่ต้องการ
- ดาวน์โหลดทีละไฟล์ หรือทั้งหมดเป็น `.zip`
- ชื่อซ้ำจะเติม `(2)`, `(3)` ให้อัตโนมัติ, อักขระที่ห้ามใช้ในชื่อไฟล์ (เช่น `/`) จะถูกแทนด้วย `-`
- **ไฟล์ PDF ไม่ถูกอัปโหลดไปที่ไหน** — ประมวลผลในเบราว์เซอร์ทั้งหมด (log ส่งเฉพาะชื่อไฟล์และสถิติ)
- ไลบรารีและข้อมูลภาษาไทยอยู่ในโฟลเดอร์ `vendor/` ทั้งหมด ไม่ต้องพึ่ง CDN ภายนอก

## บันทึกการใช้งาน (Log)

| เหตุการณ์ | ข้อมูลที่บันทึก |
|---|---|
| เข้าใช้งาน | เวลา, รหัสเครื่อง, ขนาดจอ, ภาษา, timezone |
| อัปโหลดไฟล์ | ชื่อไฟล์, จำนวนหน้า, ขนาดไฟล์ |
| อ่านข้อความเสร็จ | เวลาที่ใช้, จำนวนหน้าที่อ่านได้ครบ/บางส่วน/ไม่ได้, เลข PO ที่พบ |
| ส่งออกไฟล์ | ZIP/ทีละไฟล์, จำนวนเอกสาร, ชื่อไฟล์ที่ส่งออกทั้งหมด, จำนวนช่องที่ผู้ใช้แก้เอง, เอกสารหลายหน้า, หน้าที่ข้าม |
| ล้างไฟล์ / ข้อผิดพลาด | รายละเอียดข้อผิดพลาด (ขั้นตอน + ข้อความ) |
| ออก/ซ่อนหน้า | ระยะเวลาใช้งาน, สรุปจำนวนไฟล์/หน้า/เอกสารในรอบนั้น |

ผู้ใช้ถูกระบุด้วย **รหัสเครื่อง** (เช่น `DEV-43D33EDD`) ที่สุ่มสร้างและเก็บในเบราว์เซอร์ แสดงอยู่มุมขวาบนของหน้าเว็บ
(ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเบราว์เซอร์ จะได้รหัสใหม่)

ดูสถิติได้ 2 ทาง:
1. เปิด Google Sheet โดยตรง — ชีต `Logs` (ข้อมูลดิบ) และ `สรุปรายวัน` (นับเหตุการณ์ต่อวัน)
2. หน้า `admin.html` บนเว็บ — สรุปตัวเลข, รายวัน, แยกตามเครื่อง, กิจกรรมล่าสุด (ใส่ `ADMIN_KEY`)

## ติดตั้ง

### ขั้นที่ 1 — ตั้งค่า Google Sheets สำหรับเก็บ Log

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `PO Splitter Logs`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิม แล้ววางเนื้อหาจากไฟล์ `apps-script/Code.gs`
4. แก้บรรทัด `const ADMIN_KEY = 'change-me-to-a-secret';` เป็นรหัสลับของคุณ
5. เลือกฟังก์ชัน `setup` ที่แถบด้านบน → กด **Run** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … → Allow)
6. กด **Deploy → New deployment** → รูปเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด Deploy แล้ว **คัดลอก Web app URL** (ลงท้ายด้วย `/exec`)

> ถ้าแก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version** ไม่เช่นนั้นจะยังใช้โค้ดเก่า

### ขั้นที่ 2 — ใส่ URL ในเว็บ

แก้ไฟล์ `js/config.js`:

```js
LOG_ENDPOINT: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

(ถ้าเว้นว่าง ระบบยังใช้งานได้ปกติ แค่ไม่บันทึก log)

### ขั้นที่ 3 — เอาขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "PO Splitter"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/po-splitter.git
git push -u origin main
```

จากนั้นใน GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/po-splitter/`

หรืออัปโหลดผ่านหน้าเว็บ GitHub: สร้าง repo ใหม่ → **Add file → Upload files** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `vendor/`) ขึ้นไป

> **หมายเหตุ:** GitHub Pages ของ repo แบบ Public ทุกคนที่มีลิงก์เข้าถึงได้ (ข้อมูล PDF ไม่รั่วเพราะประมวลผลในเครื่อง)
> ถ้าต้องการจำกัดเฉพาะคนในองค์กร ต้องใช้ GitHub Enterprise (private Pages) หรือโฮสต์ภายใน

### ทดสอบในเครื่อง

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ `index.html` ตรงๆ จะใช้ OCR ไม่ได้):

```bash
python -m http.server 8000
# แล้วเปิด http://localhost:8000
```

```
index.html            หน้าหลัก
admin.html            หน้าสถิติสำหรับผู้ดูแล
css/style.css
js/config.js          ← ตั้งค่า (LOG_ENDPOINT, ความยาวชื่อ, ตัวคั่น)
js/app.js             อัปโหลด / แสดงผล / OCR / แยกไฟล์ / ZIP
js/parser.js          กติกาดึงเลข PO และชื่อสินค้าจากผล OCR  ← แก้ที่นี่ถ้ามีแบบฟอร์มใหม่
js/logger.js          ส่ง log ไป Google Sheets
apps-script/Code.gs   โค้ดฝั่ง Google Sheets
vendor/               pdf.js, pdf-lib, JSZip, Tesseract.js + ข้อมูลภาษาไทย
```

## ข้อจำกัด / ข้อควรรู้

- OCR ภาษาไทยอ่านผิดได้บ้าง (ผลทดสอบกับไฟล์ตัวอย่าง: เลข PO ถูก 8/8, ชื่อสินค้าใกล้เคียงทั้ง 8 แต่มีตัวสะกดผิดบางคำ เช่น “UPS” อ่านเป็น “บ5ร”) — **ควรตรวจชื่อก่อนดาวน์โหลดทุกครั้ง**
- สแกนที่ความละเอียด 200–300 dpi จะอ่านได้แม่นกว่า
- ถ้ามีแบบฟอร์ม PO จากระบบอื่นที่รูปแบบเลขต่างไป ให้เพิ่ม pattern ในฟังก์ชัน `findPONumber` ใน `js/parser.js`
- ครั้งแรกที่เปิดจะโหลดตัวอ่านภาษาไทย (~8 MB) หลังจากนั้นเบราว์เซอร์จะ cache ไว้
- Endpoint ของ Apps Script เป็นแบบเปิด (ใครมี URL ก็ส่ง log ได้) เหมาะกับการใช้ภายใน
